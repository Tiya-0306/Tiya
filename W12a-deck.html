今天的問題

怎麼用最少的步驟，
把一篇 Markdown 新聞稿
變成一個有網址的網站？

答案：Astro + GitHub Pages

概念

Astro 是什麼？

一個靜態網站產生器。你寫 Markdown，它幫你變成漂亮的網頁。

靜態網站 ✅

速度快、安全、免費託管
適合新聞、部落格、作品集

動態網站（WordPress）

要付主機費、慢、容易被駭
適合需要後台登入的網站

GitHub Pages = 免費的網站空間。推上去就有網址。

流程

從零到上線，5 步驟

  1. npm create astro@latest — 建專案
  2. 把新聞稿 .md 丟進去
  3. git push — 推上 GitHub
  4. 等 30 秒 — GitHub Actions 自動部署
  5. 打開 https://你的帳號.github.io/news/

你今天要做的就是這件事。
