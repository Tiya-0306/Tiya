這是 W12 課程的完整教材，教你如何用 Astro 建立新聞網站並部署到 GitHub Pages。

- `030_tasks.md` - 任務清單
- `035_pipeline-guide.md` - Pipeline 操作指南
- `040_prompts.md` - Prompt 範例
- `050_homework-guide.md` - 作業指南

## 🚀 快速開始

1. 閱讀 `010_README.md` 了解課程架構
2. 跟著 `035_pipeline-guide.md` 建立你的第一個 Astro 網站
3. 參考 `050_homework-guide.md` 完成作業

## 📖 學習路徑

1. **Phase 1**：建立 Astro 專案
2. **Phase 2**：部署到 GitHub Pages
3. **Phase 3**：客製化網站
4. **Phase 4**：一稿多發（選做）

## 🎯 學習目標

- 學會使用 Astro 建立靜態網站
- 掌握 GitHub Pages 部署流程
- 了解 Markdown 內容管理
- 實踐一稿多發的內容策略

## 📝 作業要求

- 建立一個新聞網站並部署上線
- 至少包含 2 篇文章
- 撰寫 requirement.md（至少 2 條 user story）
