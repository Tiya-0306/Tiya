課堂實作步驟

  1. 用 yt-dlp 下載一段 YouTube 影片的音檔
  2. 用 Vibe 或 rescrit-lite 轉錄成逐字稿
  3. 校對前 3 分鐘，記錄錯誤類型
  4. 把逐字稿改寫成 300 字新聞稿
  5. 繳交：SRT + 校稿記錄 + 新聞稿
💡 跟 agent 說：「幫我下載這段 YouTube 影片的音檔，然後用 Whisper 轉錄成 SRT」
